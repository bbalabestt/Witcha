# Logos

The WITCHA MATCHA wordmark, text converted to outlines (no fonts needed). Use these files as they are: don't recolour beyond the versions supplied, stretch or retype them.

- `witcha-matcha_large_blue.svg`: the main logo. Website header, print, anything 40 mm / 160 px wide or more.
- `witcha-matcha_large_gold-foil.svg`: for gold foil printing; on screen it is a stand-in.
- `witcha-matcha_large_reversed-ivory-gold.svg`: on deep blue backgrounds.
- `witcha-matcha_large_black.svg`: one-colour jobs.
- `witcha-matcha_small_blue.svg`, `witcha-matcha_small_reversed-ivory-gold.svg`: from 25 mm / 100 px wide.
- `witcha-matcha_small-no-rules_blue.svg`, `witcha-matcha_small-no-rules_reversed-ivory.svg`: below 25 mm / 100 px, down to 18 mm / 64 px.
- `witcha-matcha_social-avatar_deep-blue.svg`: 1080 × 1080 profile picture.

The full set (white and black versions of every size, plus PNGs) is in `witcha-matcha_logo-files_v1.zip`.
